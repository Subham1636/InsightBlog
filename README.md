# InsightBlog

A modern, responsive blog website built using HTML, CSS, and JavaScript as part of the **CodSoft Internship**.

## About the Project

InsightBlog is a blog website designed to provide a clean and user-friendly reading experience. It features articles related to technology, design, lifestyle, and productivity.

The website includes a responsive layout, interactive search, category filtering, popular tags, and individual article pages.

## Features

* Responsive design for desktop and mobile devices
* Blog articles displayed in card layout
* Search articles by title and description
* Filter articles by category
* Popular Tags filtering
* Load More functionality
* Individual article pages
* Related articles section
* Social sharing buttons
* Comment form with submission confirmation
* Dark and light theme toggle
* Footer with LinkedIn and GitHub links

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Font Awesome
* Unsplash images

## Project Structure

## How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

No additional installation is required.
